OSINT Threat Analyzer - асинхронный микросервис для проверки утечек среди доменов, IP-адресов и email почты.

Он автоматизирует работу аналитических сервисов. Вместо ручного поиска, эта система параллельно может опрашивать несколько площадок за вас. На данный момент для разработки это только AlienVault OTX (базы угроз), так как он бесплатный.

Ядро на FastAPI, это позволяет проводить асинхронные запросы, опрашивать все сервисы одновременно, не блокируя сервер. Redis кэширует ответы, чтобы отдавать результаты повторных проверок мгновенно. Настроен пул соединений, позволяющий не упасть при наплыве тысяч пользователей. Проект полностью изолирован Docker. Настроены лимиты для защиты от DDoS атак. Стоит Nginx для шифрованнного HTTPS трафика, то есть сайт защищен. Порты изолированы, никто не имеет прямого доступа к базе данных.

Этим сайтом я хотел показать и доказать свою способность к созданию хайлоад системы, с защитой и надежностью на современных фреймворках которые являются золотым стандартом.
